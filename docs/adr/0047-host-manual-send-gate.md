# ADR 0047: Host内の手動送信ゲート

2026-10-25 / Issue #4 / PR #10。

製品HTTPを接続する前段として、`sumibi-host`にOS非依存の手動送信ゲートを置く。
Host workerだけが呼び、Transport呼出しの前と結果返却の前に、同じ設定版・認可版・
接続先・手動同意・資格情報を確認する。変更、取得不能、失効、期限切れ、不正応答では
結果を返さない。自動再試行や接続先の代替は行わない。返した結果も暫定であり、
所有TSFは編集対象と版を改めて検査する。

接続先の識別子はscheme・host・port・base pathから作る。hostはASCII DNS名か
IPアドレスだけを受け付け、小文字化またはIP標準表記へ正規化する。
HTTPは`localhost`またはloopback IPに限る。曖昧なpath、query、fragment、
percent escapeは現段階で拒否する。未対応のURLを勝手に解釈して同意を流用しない。
資格情報はHostメモリーの非Debug型で持ち、同じ`Arc`が2回のスナップショットで
保持されることを確認する。永続資格情報の読み出し方と更新世代の発行は後続実装。

模擬Transportでは送信前の同意・版・接続先・キー拒否、通信中のキー交換後の結果破棄、
入力・期限・応答上限を検証する。実HTTP、TLS、リダイレクト・プロキシ、
設定JSON、Credential Manager、同意UIは未実装。このゲートは送信直前の
認可変更との競合を単独では解消しない。実Transportは送信時の政策確認と
リダイレクト/自動再送の拒否を別途実証する。
