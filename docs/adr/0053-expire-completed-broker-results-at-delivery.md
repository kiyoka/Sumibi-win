# ADR 0053: 完成済みBroker結果の配送時期限

2026-10-25 / Issue #4 / PR #10。

Brokerの処理が期限内に終わっても、所有スレッドが結果を受け取る前に期限を
越えることがある。単発`BrokerJob::Completion`と再利用`Worker::Completion`に
要求期限を保持し、成功本文を読む時点で期限切れなら`Timeout`を返す。
Workerの診断用`exchange()`も期限後は結果を公開しない。既に確定した
失敗の分類は維持し、明示取消は従来どおり優先する。

実子BrokerのWorker検査で、期限内に完成した結果を期限後まで保持し、
成功本文と交換情報が公開されないことを確認した。単発Jobには期限後の
完成済み成功結果を拒否する単体検査を追加した。実DLL/TSFの既存
`broker-test`21ケースと容量検査も成功した。

この検査は所有スレッドへの配送境界の補強である。結果取得後、TSF編集までの
期限検査は引き続き所有側の`ManualEdit`が担当する。
