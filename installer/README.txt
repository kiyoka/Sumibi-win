Sumibi for Windows x64 — インストールと利用開始
https://github.com/kiyoka/Sumibi-win

1. インストール

ZIPをすべて展開してから Install.cmd をダブルクリックします。
UACの確認後、64-bit Windowsの Program Files\Sumibi に配置・登録します。
スタートメニューと、次回ログオン時にHostを起動する設定を作成します。
既定のIMEは変更しません。初回のHostはスタートメニューから開いてください。

2. 初期設定（通常ユーザーで実行）

スタートメニュー → Sumibi → Sumibi Settings を開きます。
接続先のホスト名（https://を除く）、利用可能なモデル名、パスを入力し、
「設定を保存」を押します。パスは /v1 など、接続先の仕様に合わせます。
続いてAPIキーを入力して「キーを保存」を押します。
設定とAPIキーは現在のWindowsユーザーに保存します。
管理者として設定画面を起動する必要はありません。

3. 変換を試す

Sumibi Background Host を開きます。
接続先・モデルを確認して、送信管理画面で外部送信への同意を有効にします。
この同意はHostを終了すると失効します。自動起動だけでは送信を許可しません。
対象アプリを開き、Win+SpaceでSumibiを選びます。
nihongo と入力してCtrl+J、または文字列を選択してCtrl+Jを押します。
変換後はCtrl+ZでUndoを確認します。
AntigravityなどのElectron系アプリを含む互換性はIssue #16で検証中です。
文字入力ができることと、変換・置換・Undoができることは別の確認項目です。

4. 更新・同じ版の再インストール

新しいZIPを展開してInstall.cmdを実行します。
毎回新しい版フォルダーを作り、使用中の旧DLLとEXEは上書きしません。
インストール先にあるHostだけを停止します。他のアプリは終了しません。
更新後は、Sumibiを使用していたアプリを再起動し、Hostを開き直してください。
旧版ファイルはアンインストールまで保持します。
登録などに失敗した場合は成功と表示せず、復旧用の配置と記録を残します。
問題を解消してからInstall.cmdを再実行してください。

5. アンインストール

スタートメニュー → Sumibi → Uninstall Sumibi を開くか、
インストール先のUninstall.cmdを実行します。
登録解除を確認した後、起動設定・ショートカット・管理対象ファイルを削除します。
使用中のDLLが残るとエラーを表示します。アプリを終了して再実行してください。
再起動時の自動削除は予約しません。無関係なファイルは残します。
ユーザー設定と資格情報ストアのAPIキーは削除しません。
このインストーラーより前の手動配置は自動削除の対象外です。

6. 詳細

Windows PowerShell 5.1以降を使用します。
Install.ps1 -NoStartup でログオン時の自動起動を無効にできます。
-Silent は対話表示の抑制用で、UACの承認を省略するものではありません。
インストール先はProgram Files\Sumibiに限定しています。
SHA256SUMS.txtとpackage.jsonは破損確認用です。発行者の署名ではありません。
不正・破損した既存設定は上書きせずエラーにします。
