========================================================================
  Sumibi IME for Windows (x64) - インストール・利用ガイド
========================================================================

■ 概要
Sumibi（炭火）は、ローマ字をそのまま入力し、Ctrl + J で直前の文字列を
瞬時にかな漢字変換できる、高速・直感的な Windows 用 次世代 IME です。
（TSF: Text Services Framework 準拠）

------------------------------------------------------------------------
■ インストール方法（簡単 2 ステップ）
------------------------------------------------------------------------
1. 本フォルダ内の「Install.cmd」をダブルクリックして実行します。
2. ユーザーアカウント制御（UAC）の昇格ダイアログが表示されたら「はい」を押します。
   自動的に C:\Program Files\Sumibi に配置され、IME が登録されます。

※ 既定の IME は変更されません。安全にお試しいただけます。

------------------------------------------------------------------------
■ 初回セットアップ（API キーの設定）
------------------------------------------------------------------------
インストール完了時、またはスタートメニュー「Sumibi」→「Sumibi Settings」
を開いて、OpenAI API キーを入力・保存してください。

------------------------------------------------------------------------
■ 使い方
------------------------------------------------------------------------
1. メモ帳やブラウザ、エディタを開きます。
2. [Win + Space] キーを押して、入力方式を「Sumibi」に切り替えます。
3. 普通にローマ字を入力します（例: nihongo）。
4. そのまま [Ctrl + J] を押すと、直前のローマ字が漢字に変換されます！
5. 複数候補がある場合は候補リストから選択、または [Ctrl + Z] で 1 手 Undo できます。

------------------------------------------------------------------------
■ アンインストール方法
------------------------------------------------------------------------
・スタートメニュー「Sumibi」→「Uninstall Sumibi」を実行するか、
・本フォルダ内の「Uninstall.cmd」をダブルクリックしてください。
レジストリ登録・ファイル・スタートアップ設定が綺麗に削除されます。
（API キー等の個人設定は保護されます）
